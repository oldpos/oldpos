কাউন্টার এখন **Google অ্যাকাউন্ট ধরে** গোনে (ইমেইল শিটে যায় না, শুধু একটা বেনামী ফিঙ্গারপ্রিন্ট যায়) এবং `users` নামের **নতুন ট্যাবে** জিরো থেকে শুরু হয়। আগের `devices` ট্যাবের ডেটা আর গোনা হবে না।

1. শিট খুলে **Extensions → Apps Script** এ যান।
2. পুরনো কোড মুছে `tools/user-counter.gs` এর নতুন কোড পেস্ট করুন → **Save**।
3. **Deploy → Manage deployments → ✏️ (Edit) → Version: New version → Deploy**। (Who has access = **Anyone** থাকতে হবে। এভাবে করলে URL একই থাকে, `config.js` বদলাতে হবে না।)
4. ব্রাউজারে `আপনার-URL/exec?a=count` খুলুন → `{"ok":true,"total":0}` আসলে ঠিক আছে।
5. যেকোনো সময় আবার ০ করতে চাইলে Apps Script এ `resetToZero` ফাংশন Run করুন।

# ইউজার কাউন্টার সেটআপ (Google Sheet + Apps Script)

সময় লাগবে প্রায় ৫–১০ মিনিট। খরচ নেই। শুধু একটা Google অ্যাকাউন্ট লাগবে।

**কীভাবে কাজ করে:** কেউ অ্যাপ খুললে তার ডিভাইসের একটা র‍্যান্ডম আইডি আপনার Google Sheet-এ একবার জমা হয়। শিটের সারি সংখ্যাই হলো মোট ইউজার। একই ডিভাইস থেকে লগইন, লগআউট বা ডেটা মুছলেও আবার গোনা হয় না। নাম, ইমেইল বা দোকানের কোনো তথ্য শিটে যায় না।

---

## ধাপ ১: Google Sheet তৈরি করুন
1. https://sheets.google.com এ যান এবং **Blank** (ফাঁকা) শিট খুলুন।
2. উপরে নাম দিন, যেমন `Old POS Users`।

## ধাপ ২: Apps Script খুলে কোড বসান
1. শিটের মেনু থেকে **Extensions → Apps Script** এ ক্লিক করুন। নতুন ট্যাবে এডিটর খুলবে।
2. এডিটরে আগে থেকে থাকা সব কোড (`function myFunction() {}`) মুছে ফেলুন।
3. প্রজেক্টের `tools/user-counter.gs` ফাইলটা খুলে পুরো কোড কপি করে এখানে পেস্ট করুন।
4. উপরের **Save** (💾) বাটনে ক্লিক করুন। প্রজেক্টের নাম চাইলে `Old POS Counter` দিন।

## ধাপ ৩: Web App হিসেবে Deploy করুন
1. ডানদিকের উপরে **Deploy → New deployment** ক্লিক করুন।
2. **Select type** (⚙️ চিহ্ন) থেকে **Web app** বেছে নিন।
3. এভাবে সেট করুন:
   - **Description:** `v1`
   - **Execute as:** **Me** (আপনার ইমেইল)
   - **Who has access:** **Anyone** ← এটা ঠিক না থাকলে কাউন্টার কাজ করবে না
4. **Deploy** ক্লিক করুন।
5. **Authorize access** আসবে। আপনার Google অ্যাকাউন্ট বেছে নিন।
   - "Google hasn't verified this app" দেখালে **Advanced → Go to Old POS Counter (unsafe)** চাপুন, তারপর **Allow** করুন। এটা আপনারই নিজের স্ক্রিপ্ট, তাই নিরাপদ।
6. শেষে **Web app URL** পাবেন, যা `https://script.google.com/macros/s/AKfy.../exec` এর মতো দেখতে। **Copy** করে রাখুন।

## ধাপ ৪: URL সঠিক কিনা পরীক্ষা করুন
ব্রাউজারের নতুন ট্যাবে কপি করা URL-এর শেষে `?a=count` যোগ করে খুলুন:

```
https://script.google.com/macros/s/AKfy.../exec?a=count
```

এই লেখা দেখালে সব ঠিক আছে:

```
{"ok":true,"total":0}
```

শিটে `devices` নামে একটা নতুন ট্যাব নিজে থেকেই তৈরি হয়ে যাবে (এটা ঠিকই আছে, মুছবেন না)।

## ধাপ ৫: অ্যাপে URL বসান
1. প্রজেক্টের `js/core/config.js` ফাইল খুলুন।
2. `userCounterApi: ''` এর দুই কোটের মধ্যে URL বসান:

```js
userCounterApi: 'https://script.google.com/macros/s/AKfy.../exec',
```

3. এখন যে সংখ্যা মেনুতে দেখাচ্ছেন (যেমন ১০৬৪) সেটা `userCountOffset` এ লিখুন। এতে গণনা ওই সংখ্যা থেকেই চলতে থাকবে:

```js
userCountOffset: 1064
```

4. ফাইল সেভ করে সাইটে আপলোড (পাবলিশ) করুন।

## ধাপ ৬: কাজ হচ্ছে কিনা দেখুন
1. সাইট খুলুন (একটা নতুন ডিভাইস বা ব্রাউজার ভালো)। কয়েক সেকেন্ড পর মেনুর "Total users" সংখ্যা এক বাড়বে।
2. Google Sheet এর `devices` ট্যাবে একটা নতুন সারি আসবে।
3. একই ডিভাইসে পেজ রিলোড বা লগআউট/লগইন করলে সংখ্যা আর বাড়বে না। এটাই ঠিক।

## স্ক্রিপ্ট বদলালে কী করবেন
কোড এডিট করলে শুধু Save যথেষ্ট না। **Deploy → Manage deployments → ✏️ (Edit) → Version: New version → Deploy** করতে হবে। URL একই থাকবে।

## সমস্যা হলে

| সমস্যা | সমাধান |
|---|---|
| সংখ্যা `—` দেখাচ্ছে | `userCounterApi` এ URL বসানো হয়েছে কিনা, আর URL `/exec` দিয়ে শেষ হয়েছে কিনা দেখুন |
| ধাপ ৪ এ লগইন পেজ বা এরর আসছে | Deploy এ **Who has access = Anyone** করে নতুন ভার্সন Deploy করুন |
| সংখ্যা বাড়ছে না | নিজের ফোনে নিয়ে নতুন ব্রাউজার দিয়ে খুলুন। একই ডিভাইস একবারই গোনা হয়। ডেস্কটপ টেস্ট ব্রাউজার বা বট গোনা হয় না |
| সাইটে পুরনো ডিজাইন/সংখ্যা | ব্রাউজারে হার্ড রিলোড করুন (Ctrl+Shift+R) বা অ্যাপ বন্ধ করে আবার খুলুন |

## জানা দরকার
- **লাইভ:** অ্যাপ খোলা থাকলে প্রতি ৬০ সেকেন্ডে সংখ্যা আপডেট হয়। মোট সংখ্যা ৩০ সেকেন্ডের জন্য ক্যাশে থাকে, তাই শিটে চাপ কম পড়ে।
- **সীমা:** Apps Script একসঙ্গে প্রায় ৩০টা রিকোয়েস্ট চালাতে পারে। বহু হাজার ইউজার একসঙ্গে অনলাইনে থাকলে `js/services/guard.js` এ `60000` কে `120000` করে দিন।
- **ডেটা:** শুধু `devices` ট্যাবের A ও B কলাম (আইডি ও সময়)। ট্যাবের নাম বদলাবেন না, আর সারি হাতে মুছলে সংখ্যা কমে যাবে।
- **ইউজার রিসেট:** `devices` ট্যাবের হেডার ছাড়া সব সারি মুছলে কাউন্ট ০ থেকে শুরু হবে (মেনুতে `userCountOffset` যোগ হয়ে দেখাবে)।
